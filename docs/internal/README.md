# Internal engineering documentation

This directory preserves engineering history and implementation records that are useful for maintenance, auditability, and future planning but are not part of the primary product-facing README narrative.

## Contents

- `engineering-history/project-status.md` — implementation progress tracker and publication record.
- `engineering-history/phase-history-audit.md` — reconciled phase completion, commit, and tag audit.
- `engineering-history/roadmap.md` — historical implementation blueprint and sequencing contract.
- `engineering-history/requirements-traceability.md` — requirements-to-implementation traceability.
- `engineering-history/development-workflow.md` — milestone-oriented validation and release workflow used during implementation.
- `engineering-history/system-design-visuals-history.md` — historical architecture diagrams and workflow diagrams from the implementation sequence.
- `engineering-history/phases/` — historical implementation contracts.
- `engineering-history/completion-reports/` — implementation and validation summaries.

Primary system architecture, data model, threat model, failure model, capacity model, operations hardening, architecture decisions, and current-state system-design visuals remain in the top-level `docs/` directory.
